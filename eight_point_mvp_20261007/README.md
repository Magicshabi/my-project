## 接入依据与实现要求

官方备份`system_task_handle.cpp`的`action_write_servo_positions`使用`servo.sync_write_pos_speed`回放关节位置，可作为核对入口。当前备份动作组按时间发送、默认速度2000和加速度200，不适合直接把八个稀疏端点按原时间逻辑塞进去，也未证明设备当前版本支持同一路径。

版本匹配后再选择经过验证的实际运动接口，保持官方必要初始化。新增模块应具备：

1. 上电不自动回放；独立启动、单点推进及一次完整八点流程。
2. 执行前检查实时反馈、点位格式、当前舵机设置及起点接近程度；不直接从未知姿态跳到点1。
3. 使用明确的低速轨迹生成方式，不将原始编码器值误用为XYZ。关节插值不等于末端直线或无碰撞，八段路径仍需实测。
4. 每点依据多帧稳定误差判断到达；反馈失联、目标无跟随、超时和用户停止时禁止继续下一段。
5. 单独确认实际电机停止接口；仅修改ESP32状态不能声称已停止AT32正在执行的动作。
6. 留存源程序、数据、构建版本和每段实际位置日志，完整流程通过后才标记已验证。

## 当前执行入口（电脑侧，保留现有固件）

官方上位机`debug_host_gui.py::move_single_servo`将`<BhH>`（ID、原始位置、时间）发往ESP32的CMD51。本执行器采用相同入口；反馈仅采用CMD65的六组`(实际编码器值,角度)`，不将CMD11的目标缓存用于到位验收。

从本项目根目录运行，先为本地pyserial指定路径：

```powershell
$env:PYTHONPATH='A:\NEXarm\Claude\.toolchains\esptool-py-4.5.1'
python -B eight_point_mvp_20261007\official_replay.py plan
python -B eight_point_mvp_20261007\official_replay.py inspect --port COM9
```

`plan`完全离线。`inspect`仅发版本/CMD65查询，不主动切换RTS/DTR；驱动打开USB仍可能让主控复位，因此连接前需要托稳。上位机须关闭或释放端口。

下列是动作入口，只有完成对应阶段的现场准备和前置核对后使用，不是默认启动操作：

```powershell
python -B eight_point_mvp_20261007\official_replay.py probe --port COM9 --execute
python -B eight_point_mvp_20261007\official_replay.py point --point 1 --port COM9 --execute
python -B eight_point_mvp_20261007\official_replay.py point --point 2 --port COM9 --execute
# 点2～8逐段验证并确认路径后，在点1附近启动完整回放：
python -B eight_point_mvp_20261007\official_replay.py run --port COM9 --execute
```

- probe仅张开ID6八个编码器刻度，不自动回退。
- point1要求当前位置距目标每轴不超过350刻度；其他point要求起始姿态在前一点每轴±8内。run要求从点1附近开始。超限拒绝，不偷偷夹紧目标值或跳过点位。
- 以最多8刻度的小步沿关节空间插值；每步五帧稳定（跨度至少0.3秒、波动不超过2、目标误差不超过3）后才继续。固定1000ms参数，避免官方`20000/time_ms`整数计算得到零速度。
- 反馈超过0.6秒不更新、其他轴/运动轴偏离小步包络、6秒未到位均中止后续步骤，不重试。
- 停止方式：运行终端Ctrl+C或Q/Esc，或在控制台打印的本次日志目录创建空文件`STOP`。不使用机械臂KEY1/KEY2，当前固件对这些按钮有自己的功能。
- 中止时仅对本次操作过的轴尝试“目标=最新实测位置”，要求反馈不旧于0.25秒且没有串口写入错误。日志只记`hold_requested`，不声称硬件已经停机；异常时现场托稳并断舵机电源。
- `success`只表示所选模式按反馈完成；完整八点另记`eight_targets_reached_by_feedback`，现场观察/无碰撞仍单独验收，不自动将`full_playback_validated`置真。
- 每次日志独立存入`runs/<时间>_<随机标识>`，包含原始接收、逐条发送意图及写入结果、六轴反馈、终态。无NVS写入，无力矩/模式/零偏/ID/OTA操作。
