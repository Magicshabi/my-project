# 连续作业采集指南

## 1. 环境和初始化（不连接设备）

以下均为PowerShell命令，从仓库根目录执行：

```powershell
Set-Location A:\NEXarm\Claude
$py = 'C:\Users\1\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
$task = 'A:\NEXarm\Claude\连续作业采集'
$env:PYTHONPATH = 'A:\NEXarm\Claude\.runtime_deps\serial_capture'
$env:PYTHONIOENCODING = 'utf-8'
& $py “$task\capture_collection.py” init --layout-id continuous-20261012-v1
```

初始化只做一次；如已存在scene.json和13个主文件，直接接着采，不重复init。初始化遇到任何已有JSON会拒绝覆盖。场地版本名称只是数据标识，不是现场验证结论。

固定四个源篮、区域P1/P2/P3及支架位置，保留场地照片或尺寸说明到本目录。移动固定位置后建立新场地版本，不把不同场地的数据混进同一会话。

采集顺序：P0→红到P1/P2/P3→黄到P1/P2/P3→蓝到P1/P2/P3→绿到P1/P2/P3。每条内部严格S1～S8。

## 2. d6a离线导入（推荐，不连串口）

在上位机录入并试运行动作组，导出 `.d6a`，离线导入为主文件。导入不打开串口、不驱动机械臂，几秒完成一条路线。

1. 上位机按 S1～S8 录入一条路线（P0 录 1 帧）。可分批保存成多个文件，导入时按顺序传入。
2. 在上位机试运行，肉眼确认轨迹无碰撞、夹爪动作正确。
3. 先检查再写入：

```powershell
& $py "$task\import_d6a.py" 前半.d6a 后半.d6a --color 红 --target P1 --dry-run
& $py "$task\import_d6a.py" 前半.d6a 后半.d6a --color 红 --target P1 --observed '上位机试运行无碰撞，夹取正常'
& $py "$task\import_d6a.py" P0.d6a --home --observed '...'
```

ID6 规则（导入时自动写入，执行器不再叠加）：
- S3 夹紧目标 = 示教 S3 的 ID6 + 200，封顶软件上限 2731；S4～S6 继承 S3。
- S1/S2/S7/S8 及 P0 的 ID6 目标 = 示教值。

导入只写空主文件；已有点位的路线（包括串口采集的）一律拒绝，重采用新采集目录。同一路线不混用两种来源。每帧刻度须在软件范围内，S3/S7 相对前一点 ID1～5 变化不超过 12 刻度。

d6a 点标记 `source: d6a_import`，记录文件名、帧号和 SHA256，没有串口样本和设备配置。它是上位机目标值，不是实测反馈；实测和稳定性在执行器每步到位时检查。

反向导出（把主文件转回动作组，在上位机复核）：

```powershell
& $py "$taskoute_to_d6a.py" --color 红 --target P1 --output 红到P1_复核.d6a
```

## 3. 批量串口采集（手动摆位）

没有d6a文件时用此模式。批量模式一次启动采集整条路线或P0，大幅减少命令和锁操作。每点仍需手动摆位，但输入简化为按回车。

**采集P0初始位**：

```powershell
& $py “$task\capture_collection.py” batch --home --port COM11 --holder claw --grip-target 1800
```

启动后按提示摆位、断开上位机、按回车采集。采完自动释放锁。

**采集一条完整路线**（例如红→P1）：

```powershell
& $py “$task\capture_collection.py” batch --color 红 --target P1 --port COM11 --holder claw --grip-open 1800 --grip-close 2000
```

- `--grip-open`：S1/S2/S7/S8 张开目标
- `--grip-close`：S3 夹紧目标（S4/S5/S6 自动继承）

启动后按提示依次摆 S1～S8。每点采完显示数据，可选择：
- **回车**：保存并继续下一点
- **r**：重新摆位并重采此点
- **s**：跳过此点（稍后补采）
- **q**：退出

批量模式在启动时取锁一次，整条路线采完后释放。中途按 Ctrl+C 也会自动释放锁。

## 4. 单点采集（补采或修正用）

`--grip-target` 填上位机**实际设置的ID6目标刻度**，不是夹住后停住的反馈值。下面的 `$gripTarget` 和 `$observation` 应由Claw从本次操作取得真实值，不猜、不直接照抄旧项目数值。

需要先手动取锁：

```powershell
& $py handoff/lock.py acquire COM11 --holder claw --minutes 30 --purpose '连续作业采集'
if ($LASTEXITCODE -ne 0) { throw '取锁失败，不能继续' }
```

P0示例（已取锁）：

```powershell
# 先设置 $gripTarget 为本次ID6目标整数，$observation 为本次摆位依据
try {
    & $py "$task\capture_collection.py" capture --home --point 1 --port COM11 --holder claw --powered-sliders-confirmed --grip-target $gripTarget --observed $observation
    if ($LASTEXITCODE -ne 0) { throw '本点未保存，查看首个错误和RUN_DIR' }
} finally {
    & $py handoff/lock.py release COM11 --holder claw
}
```

红篮到区域P1的S1示例（重新摆位并取锁后）：

```powershell
try {
    & $py "$task\capture_collection.py" capture --color 红 --target P1 --point 1 --port COM11 --holder claw --powered-sliders-confirmed --grip-target $gripTarget --observed $observation
    if ($LASTEXITCODE -ne 0) { throw '本点未保存，查看首个错误和RUN_DIR' }
} finally {
    & $py handoff/lock.py release COM11 --holder claw
}
```

其余点更改 `--point`，颜色和目标对应本条路线。S1/S2/S3/S7/S8均须填写真实ID6目标；S4～S6不传`--grip-target`，工具自动继承S3目标，现场上位机也要保持该目标不变。

S3/S7仅操作夹爪，ID1～5相对前一点变化不得超过12刻度；超过时检查摆位，不提高容差绕过。夹紧目标与实际反馈分别保存，不统一再加200刻度。

工具检查8个样本、双通道一致性、软件范围、配置与锁。保存前备份旧版本，原子替换并核验SHA。采集器不会执行运动或自动替你回位。

## 5. 验证及继续

```powershell
& $py "$task\progress_tracker.py"
& $py "$task\progress_tracker.py" --verify-home
& $py "$task\progress_tracker.py" --verify 红 P1
# 全部采完后：
& $py "$task\progress_tracker.py" --verify-all
```

校验失败返回非零退出码。主文件内唯一有效点才计数；副本不计数。每条完成后由用户把篮子放回对应源位置、清空试放区域，再采下一条。

正常中断：批量模式按 Ctrl+C 退出后自动释放锁，重启 batch 命令会从主文件的下一个点继续。单点重采、重复文件或损坏文件的处理见 `数据规范.md`，不要删除旧证据或手工改点号。

收尾：记录路线ID、点号、有效点数、SHA、RUN_DIR及真实现场反馈到共享台账 `continuous-collection`，执行 `handoff/render.py` 和 `handoff/render.py --check`。不要把采集通过写成搬运通过。

## 6. 模式选择

| 模式 | 是否连串口 | 数据 | 适用 |
|---|---|---|---|
| d6a离线导入 | 否 | 上位机目标值 | 优先，空路线整条导入 |
| batch串口采集 | 是，只读 | 8样本实测 | 无d6a时；或需要实测证据 |
| capture单点 | 是，只读 | 8样本实测 | 串口路线补下一个点 |
