# 连续作业：使用说明

在 PyCharm 底部打开 **Terminal**（提示符以 `PS` 开头，不要用 Python Console），先进入目录：

```powershell
cd A:\NEXarm\Claude\连续作业采集
```

## 运行前

1. 机械臂在 P0（上位机里送回去）。
2. **上位机断开串口**。
3. 四个篮子在原位，P1、P2、P3 清空，人离开工作区，手放在电源开关旁边。

## 命令

| 想做什么 | 命令 |
|---|---|
| 跑一组（带篮） | `.\运行.ps1 红-蓝-黄` |
| 连续接指令，每次一组 | `.\运行.ps1` |
| 依次跑全部24组 | `.\运行.ps1 -All` |
| 空载跑一组（不放篮子） | `.\运行.ps1 -Empty 红-蓝-黄` |
| 只看计划，不连机械臂 | `.\运行.ps1 -Check 红-蓝-黄` |

颜色写法：`红-蓝-黄`、`红 蓝 黄`、`红蓝黄`、`red,blue,yellow` 都可以。必须是三种不同颜色，依次放到 P1、P2、P3。

脚本会自动取 COM11 锁，结束或出错时也会自动释放。

## 运行中

- 跑完一组会问结果。三篮都放对、没掉、没碰撞，输入 `yes`。
- 交互模式会出现 `指令>`，输入下一组颜色即可。输入 `q` 退出。
  - 一组跑完，机械臂停在第三篮的 S8，不回 P0。下一组开始前，先用上位机送回 P0，并把篮子复位。
- `-All` 模式下，每组之间会提示复位篮子：复位后输入 `y`，脚本自动回 P0，再跑下一组。
- 出错或越界：机械臂原地停住（带篮时保持夹紧），脚本退出，屏幕上会有 `STOP=` 说明原因。
- 急停：`Ctrl+C` 只能停后面的动作，已经发出的那一段会走完。真正急停请**断电**。

## 常见提示

| 提示 | 处理 |
|---|---|
| `COM11 被占用` | 有人正在占用串口，或上次没释放。确认没人在用后，执行 `& 'C:\Users\1\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' ..\handoff\lock.py release COM11 --holder claude` |
| `起点偏离P0 …` | 机械臂不在 P0。用上位机送回 P0 再运行 |
| `当前停在…S8，不在P0` | 上一组跑完没有回 P0。用上位机送回 P0 |
| `注意：设备配置与P0采集时不同` | 只是提醒，不影响运行 |
| `未到位已接受{…}` | 关节停在离目标 120 刻度以内，属于正常情况（ID4 最高只能到约 3085） |

每次运行的记录在 `logs/run_*/`（全组合测试在 `logs/combos_*/summary.json`）。
