## 二、选型结论

**采用「教学点位查表 + 回放」，不上视觉。** 理由：

1. 位置固定 ⇒ "识别颜色"这件事只需要一次**离散查表**（颜色 → 槽位号 → 点位）。
2. 我们已经**实测验证**了写路径（见 `golden_20261008_first_motion.md`），
   而八点数据本身就是**6 轴的舵机原始刻度**，格式与已验证写路径完全一致 → 零转换成本。
3. 视觉会引入新变量（光照、标定、遮挡），**在位置固定的前提下收益接近零、风险不为零**。
4. 竞争场景的可复现性优先：查表是确定性的，视觉是概率性的。

> **视觉的定位（可选、非必需）**：只作为**校验器**——抓取前确认"目标槽位确实有方块"、
> 抓取后确认"方块确实被带走"。做校验时只需在已知槽位的**小窗口**内判断，
> 不需要全图识别，难度低、收益实。

## 四、执行流程

```
输入颜色 c
  ↓ 查表 → (above, grip, lift) + place
  ↓ 前置检查：读实时位姿；若离 above 太远（> 起步限制），先分段接近，禁止硬跳
  ↓ 1. 移动到 c.above（张开姿态）
  ↓ 2. 下压到 c.grip
  ↓ 3. 合爪
  ↓ 4. 抬到 c.lift
  ↓ 5. 移动到 place.above
  ↓ 6. 下压到 place.down
  ↓ 7. 张开
  ↓ 8. 抬到 place.clear（撤离）
每段：多帧稳定判到位 + 超时即停、不进入下一段
```

## 五、未来难点与对策（逐条）

| # | 难点 | 现象 / 依据 | 对策 |
|---|---|---|---|
| D1 | **点间路径不可控** | 端点是关节刻度，AT32 各自插值 → 末端走弧线。实测 1→2 的 ID4 差 **1501 刻度（≈132°）**、7→8 差 **1471 刻度**，中间路径完全没被验证过 | ① 端点间补录 1~2 个中间姿态；② **先跑单轴序贯**（大行程轴先到位再动其他）；③ 低速空载首跑 + 每段目视 |
| D2 | **重复定位精度未知** | 廉价总线舵机 + 减速箱，有回差与温漂；**我们从未测过重复精度** | ① 做**往返 10 次测量**，算出真实极差 → 定容差；② 关键点**同向逼近**（总从同一侧靠近）消除回差方向差；③ 每轮前以基准点归零 |
| D3 | **到位判定可信度** | `cmd11` 与 `cmd65` **同源**（已实测逐字节相同），只证"指令被接受"，不证"物理到位" | ① 多帧稳定判据（连续 N 帧极差 ≤ 容差）；② 关键点**物理复核**；③ 台账四列：命令值 / 读数 / 稳定帧数 / 现场确认，缺一不算通过 |
| D4 | **抓持靠位置不靠力** | 合爪是"走到某个刻度"，不是力控 → 方块重量/摩擦一变就滑；夹偏一点就掉 | ① 闭合位置**过压 30~50 ticks**，用机构弹性提供夹持力；② 抬起前**低位停顿 0.3s** 让方块滑入夹口；③ （可选）加夹爪到位微动开关或电流阈值 |
| D5 | **Z 高度与方块规格耦合** | 点位里的高度是"录的时候那个方块"的高度；换批次/叠放就会空夹或压坏 | ① 按规格在查表里多一维（颜色 × 规格）；② 抓取前用 `cmd65` 复核夹爪开度 |
| D6 | **异常中断与恢复** | 断电/掉线/误触 → 臂停在半个姿态；下次从点1 还是从当前继续？ | ① **上电不自动回放**；② 每次执行前先读位姿并判断"起点接近程度"；③ 超限则**分段接近**，不硬跳（已有 350 刻度起步限制的教训） |
| D7 | **"停"不等于停下** | 只改 ESP32 状态 → AT32 正在跑的那段轨迹会继续走完 | **单独验收停止能力**：发停 → 现场确认真的停 → 记入台账 |
| D8 | **节拍/时间预算** | 每段都慢速+停顿，总时长可能超限 | ① 分段测时找瓶颈；② 用 `acc/speed` 调优（已验证路径无 time 参数）；③ 只在"接近/下压"段慢，回程提速 |
| D9 | **两条工作线无单一权威源** | 2026-10-08 已发生：重复分析 exe、结论互不相认 | `PROJECT_STATE.md`=状态权威；`.workbuddy/memory/MEMORY.md`=工程约定权威；交叉引用登记 |
