> 此前所有"已适配 / 已复用"的声明都缺这一条证据，这是唯一一次被现场目视确认的成功。

## 一、结论

**链路通了。** 用下列原始舵机写帧，机械臂夹爪（ID6）**现场目视确认做了约 44° 的张开/闭合**。

## 三、可复现的操作序列

### 1) 帧格式（回顾）

```
FF FF | ID | LEN=2+len(ARGS) | CMD | ARGS | CHECKSUM
CHECKSUM = (~sum(ID,LEN,CMD,ARGS)) & 0xFF     ← 不含两个 0xFF 帧头
```

### 2) 本次实际发送的帧（逐字节，可直接回放）

| 动作 | 帧（hex） | 解码 |
|---|---|---|
| 张开 | `ffff060a03296413050000d00770` | ID=6, LEN=10, CMD=3, ARGS=[41, 0x64=100, **1299**, 0, 0, 0x07D0=2000] |
| 合上 | `ffff060a0329646c070000d00715` | 同上，目标 **1900** |
| 回位 | `ffff060a03296407070000d0077a` | 同上，目标 **1799** |

**ARGS 结构 = `[0x29(ACC 寄存器41), acc(uint8), pos(int16 小端), 0, 0, speed(int16 小端)]`（8 字节）**

| 参数 | 本次值 | 说明 |
|---|---|---|
| `pos` | 舵机**原始刻度**（0~4095） | **不是角度、不是 XYZ**。1 tick = 360/4096 = **0.08789°** |
| `acc` | **100** | 官方 GUI 默认值 |
| `speed` | **2000** | 官方 GUI 默认值 |
| ID | **舵机号（1~6）** | ⚠️ **必须用舵机号**；`ID=0xFF` 广播对 CMD=3 **无效**（两次实验均冻结） |

### 3) 观测到的响应

| 命令 | cmd65 读数 |
|---|---|
| 1299 | 1303 |
| 1900 | 1898 |
| 1799（回位） | 1802 |

链路：rx 111 帧 / tx 13 帧，**checksum_errors = 0，resyncs = 0**。

## 六、给后续实现的三条硬建议

1. **任何"验证是否动了"的实验，幅度不得低于 ±150 ticks（≈13°）**；低于 50 ticks 的结论一律无效。
2. **不要再用 `ID=0xFF` 发原始舵机写帧**；用舵机号。
3. **到位判定**：`cmd65` 多帧稳定（连续 N 帧极差 ≤ 容差）+ 关键节点现场目视复核。
   八点数据本身是**关节刻度**，可直接送入本写帧的 `pos` 字段（无需 IK、无需 XYZ）。
