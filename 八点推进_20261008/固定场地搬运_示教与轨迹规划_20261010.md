# 固定红篮到T0：八阶段搬运技术方案

更新：2026-10-11。这是实施与验收方案，尚未证明整段搬运通过；当前采集进度由`python handoff/brief.py`从数据文件和台账提取。

## 1. 目标与分工

固定红篮、T0及障碍位置，从上方夹住固定长方形提手，完成稳定搬运和正确放置，再优化用时。最小成果是八阶段可重复执行；实际轨迹可增加过渡点，不要求仅用八个点连线。

Claw配合用户完成带电主动摆位、只读采集和落盘；Codex负责协议适配、轨迹设计、Bug检查和验收。现阶段复用已实机成功的关节运动通道及`A:\NEXarm\运动控制`基础案例。视觉、自动重规划暂不作为前置条件。

## 2. 当前证据与系统边界

六轴单独移动并恢复已有实机验证；新路线正在采集，完整回放、带载搬运、连续平滑和物理急停效果尚未验收。数据源为[主动示教JSON](data/eight_joints_powered_20261009.json)，旧八点不混入新路线。

软件限位仅用于拒绝越界输入，不能证明真实可达或避障。ID4历史单次目标未动，不能推导固定上限；GUI目标和反馈也不能用固定偏差相互换算。保留[回放诊断锁](replay_diagnostic_hold.json)，先审查再进入动作测试。

执行链：采集与反馈核对 → 点位/夹爪事件检查 → 路径检查 → 时间分配 → 下发及反馈监测。串口独占，采集显式指定COM11；现场动作交由负责采集/测试的一方执行。

## 4. 示教、路径与平滑执行

| 阶段 | 动作与验收重点 |
|---|---|
| 1 提手上方 | 张爪、对准、留下降空间 |
| 2 接近提手 | 慢速下降，提手进入夹指之间 |
| 3 夹紧 | 停稳夹持，确认不滑落 |
| 4 提起 | 带篮离开相邻物块，检查整个篮体净空 |
| 5 转运 | 保持夹持，移至T0上方 |
| 6 放下 | 慢速下降至稳定支撑 |
| 7 松爪 | 篮体受支撑后释放 |
| 8 退出 | 张爪离开提手和放置物 |

主动摆位能到达端点，不代表两端间的运动安全。关节插值通常不是末端垂直直线；接近、提起、放下应限制方向和姿态，必要时补采过渡点。第3→4及4→5段已出现约1100刻度的ID4变化，须优先审查，不能按“小步平移”理解。

碰撞检查覆盖连杆、腕部、夹爪和所夹篮体。若越过邻篮，应检查篮底是否超过邻篮顶部并保留经验证的余量；也可选择绕行。仅八点合法或夹爪中心无碰撞均不足以判定路径通过。

定时密采可帮助记录弯曲路径，但直接逐样本启停回放会保留手抖和停顿。采集后应保留关键姿态、检查拟合偏差，再分配速度/加速度；夹紧、松开和接触前后的必要停顿单独保留。圆滑处理不能改变避障通道或穿越夹持事件。

优化顺序：先核实控制器速度/时间参数及多轴下发行为，再选插值与时间参数化。先做反馈监测和超时终止，再优化段间衔接；未经接口验证，不以高频小步下发或S曲线名称保证“消除抖动”。平滑轨迹仍需在真实控制器上验证。

## 5. 实施与验收

1. Claw补齐八阶段及必要过渡点，提交姿态、原始日志、现场观察和异常摘要；Codex只按需读取，不重复全量历史。
2. 离线检查阶段顺序、点间变化、夹爪事件和路径净空。未知碰撞余量、关节同步性和急停效果分别列为待验，不自动解锁运行。
3. 验证停机手段，空载低速分段观察，再进行单次低速带载搬运。记录碰撞/滑移、落点偏差、执行耗时及异常处理。
4. 稳定后再做连续重复测试并优化速度；重复次数和允许误差随赛事要求确定，不把一次成功等同可靠性已通过。

当前最需要补齐的是夹持重复性、邻篮净空、T0允许误差和异常终止效果。相机可在后续辅助检测提手长边/方向及抓取结果，但仍需标定与深度或已知平面约束，不能仅凭二维长边直接下发三维抓取坐标。
