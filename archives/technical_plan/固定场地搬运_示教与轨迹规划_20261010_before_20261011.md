固定场地搬运：示教、连续轨迹与视觉辅助规划（2026-10-10）

状态：规划提案，尚未实施。本轮未连接机械臂串口、未写固件或控制参数。旧八点保留；新主动示教文件仍为0/8。

用户已确认：红篮、T0和障碍物位置固定；有K230和普通相机，K230可固定安装或安装在腕部；正确放置是基础得分，搬运速度是加分项。相机最终安装方式、提手尺寸、障碍尺寸、允许落点误差与赛事外设约束仍需实测或核对。

1. 推荐方案与目标

采用“电机主动到达的关键姿态 + 必要的过渡点/连续记录 + 静态环境路径检查 + 连续时间轨迹 + 执行反馈 + 视觉辅助确认”。保留八个任务阶段，不限制实际几何路点只能有八个。

优先满足不碰撞、不掉落、放置正确和稳定重复，再减少循环时间。最短几何路径不必是最快或最可靠的搬运轨迹。固定场地可在事先验证后重复执行，不必每帧重新做通用路径搜索。

八个阶段：红篮上方张开；下降到夹持位置；夹紧；提起；转运到T0上方；下降落地；松爪；退出。夹紧/松开是事件，不能只当成另外一组可连续插值的关节位置。抬起、转运、下降需要分别约束方向、姿态、速度与载荷。

2. 已核对的现有程序限制

- `replay_joint_points.py` 每小步最大40原始刻度，随后等待至少0.5秒及多组稳定回包。这是逐步诊断策略，不能原样作为流畅生产回放。小步之间连续停稳，会造成启动/停止感；尚未通过整段实机回放，不能声称已经量化了整条轨迹的机械振动。
- `nexarm/safety.py` 当前运动写入间隔至少50毫秒；`move_joint_counts` 逐轴调用它。六轴均更新时首末发送可相差约250毫秒，实际到达时间还取决于各轴行程与伺服响应。
- `运动控制/速度规划` 提供加速度与段时长的示例；`编程定点夹取搬运` 提供抓放顺序，但按固定delay推进，未形成完整碰撞检查与到位事件闭环。
- 本地HX_30HM.cpp有批量同步写接口，可作为候选；速度规划目录的该版本将ACC字段写0，各轴采用同一speed。同步写入不等于同步到达或速度连续，不能未经适配直接采用。当前固件上这条连续执行路径尚未实测验收。
- `出厂程序_backup_20260919` 中有时间戳动作帧及定时记录/回放实现，文件包含后续修改，不能当作当前固件行为的保证。10ms记录配置不证明编码器产生100Hz新数据。
- ID4目标2940、3090的移动/回位已有目视通过；3234目标完全未动，3472未正确到达。实际内部限位与目标处理仍未知，3090不是已测出的机械上限。轨迹平滑不能解决这个执行映射问题。

本地证据入口：`id4_target_comparison_20261009.md`、`replay_stop_diagnosis_20261009.md`、`replay_joint_points.py`、`../舵机基础运行逻辑/nexarm/safety.py`。现有回放诊断锁继续保留。

3. 八点之间怎样走

关节数值直线插值通常不产生末端空间直线。两端均无碰撞，也不能证明中间的肘部、腕部、线缆或篮子无碰撞。向下接近提手、带物提起、T0落地段应尽量约束末端方向及姿态；其余转运段可采用经过检查的关节轨迹。

起步先测量机械臂基座、提手抓取中心、篮体尺寸、T0和静态障碍，建立最小场地模型。工具中心应取夹指实际夹持提手的中心，不能直接将腕轴原点当作夹持点。

路径顺序：已确认的起点 → 红篮上方 → 低速接近 → 停稳夹紧 → 确认夹持 → 抬到篮底越障高度 → 转运 → T0上方 → 低速落地 → 确认落稳 → 松爪 → 退出。越障余量要覆盖姿态变化、篮体尺寸、定位误差与跟随误差，不能固定套用“夹爪高出障碍几厘米”。

转运段有必要时增加一个或数个中间路点。平滑后重新检查整条路径、关节极值和载荷空间；不能用会切角或过冲的样条直接替代人工避障路线。返回下一次起点也要单独验证；不能简单倒放夹爪事件。

在运动学模型/关节映射未验证前，人工观察和分段验证只能提供现场证据，不能冒称已有完整三维自动避障。

4. 连续记录怎样做才有效

保持电机主动到达的示教方式。连续记录用于保存人工引导的可行通道、速度变化和关键事件，不能把不受控的手抖、不必要停顿和重复读数直接逐帧复写。

建议每条记录包含：单调时间戳；六轴原始反馈；已发目标及其时间；数据来源与接收时刻/新鲜度；夹爪状态与阶段事件；可获得的电压等状态；可选的视频帧时间。会话级保存固件版本、零偏/几何配置和基座、相机安装状态。无回读能力的力矩、电流、温度字段必须标未知，不能填造数值。

先测量实际反馈更新率、延迟、重复帧及丢帧，随后确定采样频率。例如10Hz只可作为起步候选，不是已证明能力；周期查询收到缓存不等于新编码器采样。记录频率、规划采样周期与硬件下发周期分别设计。

处理流程：保留原始数据 → 清除异常/过时帧 → 标记抓取、抬起、落地等事件 → 在几何误差约束内简化冗余点 → 有约束拟合路径 → 限制各轴速度/加速度/加速度变化率 → 平滑后复查避障 → 空载分段验收。

不要让每个采样点速度都归零。允许安全转运段的过渡点连续通过；夹紧、落地和松爪等事件点停稳。过滤/拟合应保护接近方向、关键姿态及避障余量。手动操作速度无需原样保留，离线重新分配段时间。

5. 消除走走停停与抑制机械抖动

可以针对软件层的逐点停顿进行重构，并测量改善；不能承诺完全消除齿隙、供电、负载下垂或伺服调节引起的振动。

执行器需要：统一时间轴、多轴配时、连续的段间速度/加速度、受限的加速度变化、有限前瞻缓冲，以及定时跟随误差/反馈超时检测。新目标到来时下位机如何处理（覆盖、重规划、排队）必须先验证；电脑生成曲线平滑不代表伺服实际也平滑。

优先验证已有同步控制或控制器本地轨迹能力；若具备能力，将轨迹按固定周期执行，主机负责规划与监视。不能仅删除sleep或不断向串口灌更密目标。单轴验证 → 空载多轴同步 → 两段连续衔接 → 全路径 → 带载，逐级验收。

Ruckig可用于速度、加速度及jerk受限的时间轨迹，不负责障碍物规划；多途经点功能的版本/许可/云端差异需要核实，不能假设免费本地版本支持完整多点优化。
依据：https://docs.ruckig.com/md_pages_2__intermediate__waypoints.html
MoveIt也区分几何规划、时间参数化与jerk平滑；部分后处理可能改变路径，需再次碰撞检查。
依据：https://moveit.picknik.ai/main/doc/examples/time_parameterization/time_parameterization_tutorial.html

6. 摄像头和YOLO的职责

当前固定场地优先把现有普通相机固定，辅助核对红篮、提手、抓取结果及T0放置；K230可复用现有颜色识别能力。固定相机应建立相机到机械臂基座的坐标关系；腕部相机还需手眼标定并处理运动模糊、遮挡、负载与线缆变化。拆装后重新核对标定。

普通YOLO目标检测给出图像框、类别和置信度，不能直接替代关节反馈或生成可信机器人三维抓取轨迹。抓取目标是提手中心和朝向，不是整个红篮检测框的中心；若引入视觉模型，应围绕提手检测/分割/关键点定义数据。
依据：https://docs.ultralytics.com/tasks/detect

已知平面和物体高度时，可评估普通相机标定加几何约束；桌面单应性不能直接套到有高度的提手而忽略误差。高度/遮挡不确定时再考虑三维感知，不预先要求购买深度相机。

如果规则允许，ArUco/AprilTag/ChArUco可辅助场地或相机标定；位姿估计需要相机内参及标记实际尺寸，并进一步变换到机械臂坐标。标记能否留在赛场需核对规则。
依据：https://docs.opencv.org/4.x/d5/dae/tutorial_aruco_detection.html

先在接近阶段稳定估计目标并做有限校正；不要把每帧检测框抖动直接变成电机目标。视觉用于监视时也有盲区和延迟，不能作为人员安全急停的唯一依据。

8. 容易遗漏的问题

- 六个舵机包含夹爪ID6；不能把它等同于拥有任意六维末端姿态的六关节机械臂。基座朝向、腕部姿态和可达空间有耦合。
- 全臂、自碰撞、夹指开合扫过的空间、篮子与线缆都需考虑；空载安全不代表带篮安全。
- 编码器/命令/零偏/角度单位要一致；协议speed=2000不是2000ms或2000mm/s。稳定反馈不独立证明末端几何位置正确。
- 抓爪位置到位不等于夹紧力足够；提手摩擦、形变、夹爪平行度、篮体重心、带载加速度和滑移共同影响成功率。
- 高速下的供电压降、发热和刚度下降，可能导致冷机前几轮成功而后续失败。适当保留负载余量并记录重复运行结果。
- 基座松动、场地图纸位移、相机变焦/拆装会使已录坐标失效；建立复位后的参照检查。
- 反馈过期、USB断连、程序崩溃、旧命令积压、断电恢复和暂停续跑需有明确策略。停止发送不保证控制器立刻停止；不要用全部掉力矩作为持物状态的默认停机方式。
- 松爪应发生在篮体落稳之后；夹持失败应停在可恢复阶段，不继续空抓搬运。人工介入后的新姿态不能直接跳回旧轨迹中段。
- 赛规对相机、电脑、标记、定位夹具、赛前示教和人工操作的限制，需要在采购/改造前核对。

9. 交付顺序与验收

第一步：场地/提手/工具中心测量与可达性检查，记录固件/标定配置，明确静态安全通道；继续保留ID4执行问题的诊断边界。
第二步：建立单一控制入口的记录与预览工具，记录8个任务事件及必要过渡数据，检测过时反馈，不覆盖原始记录。
第三步：验证多轴同步及连续目标语义，实现平滑执行；空载逐段检查全臂扫过空间与关键接近方向。
第四步：低速带载验证夹持、落地和异常停止，再重复运行。建议以连续20次正确抓放作为一个初步验收阶段，同时统计放置误差、失败类别、单次时间及波动；这不是对可靠性或零碰撞的保证。
第五步：在保持成功率与余量的前提下优化高处转运段时间、缩短不必要停顿。接近和释放段保留精度优先的速度与事件条件。

下一步所需现场信息：固定场地带尺寸布局；提手宽厚、高度与允许夹持方向；篮体尺寸及载荷；夹指开度/接触尺寸；相机最终安装位置；允许放置误差及相关赛事限制。先获取这些信息再确定具体安全高度、轨迹与验收阈值。
