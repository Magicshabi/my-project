# ID6 单次目标写入实验 r1（不是八点回放）

用户要求先执行观察，再调整。现场已确认物块卸载、夹爪空载、机械臂托稳、远离障碍、无红灯；最近确认外接舵机电源接通。

前置只读探测中，AT32 0x5A 正常返回 CMD65 位置，但 ID6 原始寄存器 READ（3/33/40/56）两轮全部超时。目标寄存器与力矩状态没有读到。因此本实验只观察一次已知格式的位置指令是否引起预期的小位移，不凭无回复认定故障，不假装已经验证目标寄存器。

## 执行边界

- 上电不动。只有 KEY1 短按松开一次，等待 600 ms，再采五组实际位置；ID6 波动不超过 2 刻度，其他轴不超过 8。
- 仅 ID6，目标为采样位置减 8 原始刻度；方向依据本次记录中两组“开→合 / 合→开”的夹爪值确认。目标和当前位置必须留在已示教 ID6 范围内并保留余量。这不是机械限位或无碰撞证明。
- 使用本地出厂 write_pos_ex 的帧格式：ID6 / WRITE3 / 地址41，ACC5，目标位置，PWM0，速度30。
- 唯一 Serial1.write 入口经过严格白名单，只能查询 FF/65 或发送本次 ID6 的固定参数目标。禁止广播位置、其他轴、力矩、模式、ID、回位、标定、主机透传和 NVS 写入。
- 不发送开/关力矩。现有力矩若关闭，可能不运动；没有位移只能判为未证明成功，不能自动开力矩或增加步长重试。
- 一次目标发送前先消耗本次机会，UART 部分写入也不重试。本次开机后不再发送第二个位置目标。
- 观测四秒全部六轴。其他轴变化超过8刻度，ID6反向超过4或张开超过24刻度，反馈丢失超过500ms，都提示异常。
- **已发送的目标无法通过此程序撤回。KEY2 在发送前可取消，发送后只提示停止，不能作为硬件急停。异常时由现场人员切断外接舵机电源，保持机械臂支撑。**
- 完成后仅报告是否观察到对应的小位移；不代表目标寄存器确认、其他关节或八点轨迹已通过。

## 数据与验证

NVS handle_free/poses_v1 只读，不改变八点。先前完整备份和逐字节八点对照仍保留。

启动自检穷举单关节发送白名单，覆盖方向、范围边界、帧参数、未授权、目标不符、长度错误及空指针。PC 测试检查旧记录兼容和发送/存储边界。必须确认启动日志自检通过、没有自动发送目标、当前状态为 IDLE 后，才能协调现场按 KEY1。

构建脚本 `../build_single_joint_probe_r1.ps1`；启动记录脚本 `../capture_single_joint_boot.py`。动作时需另行被动录制串口，并由现场观察是否只有夹爪微动、其他关节稳定、无红灯或碰撞。
