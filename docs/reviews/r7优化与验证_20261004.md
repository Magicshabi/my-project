## 代码

- `handle_teach_r7_20261004/NexArm_Teach_Record`：完成页 KEY1 有提示；保留按键电平诊断。
- 协议参数统一 250 字节，全帧 256 字节，长度返回/接收变量改 uint16，payload+checksum 容量明确。原 24/108 字节业务格式不变。
- `error_state` 用于真实错误分类和累计统计；新增限频 rx_health/query_timeout，区分无字节、解析错误、非目标帧、半帧/噪声。
- 十六进制 217 字节缓冲，完整 JSON 在单次 Serial.write 中输出。输出不足则不发送截断快照。
- 唯一 AT32 输出仍是无参数 CMD65。没有写目标、力矩、夹爪、回位、自动回放或 OTA。

## 验证流程

- `teach_validation_r7.py`：OLED 现场确认优先；六轴逐轴两次同向小幅动作加返回核对；第一点两人观察与保存前后日志；关键节点时间戳目录留档；重启记录与指定前一份逐字节对照。
- 无串口命令写入、无主动复位；原始日志及时落盘，中止保留证据。所有“通过”仅针对各项观测，不证明无力矩或硬件无故障。
- 不统一要求 10°，不把单次保存后偏移直接判为 AT32/舵机故障，不把实际位置回读当成目标寄存器确认。
- 操作手册：`handle_teach_r7_20261004/README.md`。
