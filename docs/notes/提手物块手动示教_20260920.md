# 红色固定提手物块 → T0：手动示教

## 本轮需求与状态

- 用户确认：从上往下夹紧固定提手；物块固定放置，只测试红色，放到 T0。K230 已接好且能识别红色。
- 工作副本：`handle_teach_20260920/Color_Sorting`，版本 `1.0.2-handle-teach-r4`。r3 源码保留在原目录。
- 本版只记录和锁定手动姿态，没有启用自动搬运。KEY2 不会触发旧的默认搜索姿态，串口旧运动命令也被禁用。
- 初始姿态仍保存在 `robot_cfg/home_pos`。八个示教点使用独立的 NVS 命名空间 `handle_teach`、键 `poses_v1`，不会覆盖初始姿态。
- 开机仍释放扭矩，必须托稳机械臂；初始校准仍按 KEY1 保存并锁定。
- 完成编译不等于已烧录，也不等于实机示教验证通过。实际验证结果见下文后续记录。

## 按键操作

1. 初始姿态保存锁定后，屏幕显示 `RED handle teach / KEY1: teach prep / KEY2: NO RUN`。
2. 短按 KEY1 进入第一个点的准备页，此时仍保持锁定，不会移动或释放。
3. 屏幕显示 `Support arm first`。托住机械臂和物块后，再短按 KEY1 释放全部关节，才可轻轻拖动。不要硬扳锁住的关节。
4. 对准目标姿态，保持手指离开夹爪夹持区，托稳并短按 KEY1。程序读取五组新反馈，要求稳定且编码器范围有效，先写入当前位置目标再开启保持扭矩，检查位置偏差，然后保存并读回核验。
5. 出现 `Saved + held` 才算本点完成。KEY2 进入下一个点的准备页，仍保持当前点；再次托稳并按 KEY1 才释放。
6. 已保存点按 KEY1 可以进入重教准备页。重教一个点会使其后各点失效，需要重新示教。
7. 完成第八点后按 KEY2 显示完成页，再按 KEY2 回待机；不会自动回到初始姿态。

短按约半秒后松开。待机长按 KEY1 仍进入初始姿态校准，不是抓取点示教。松开扭矩期间 KEY2 不能跳过当前点；先保存锁定。中途取消准备页不释放扭矩；从待机重新进入示教会从第一个点开始，不自动续教。

## 八个示教点

| 屏幕标题 | 手动设置的姿态 |
| --- | --- |
| `1 Red above OPEN` | 夹爪朝下，位于红色提手正上方，开口略宽于提手，留出下降空间。 |
| `2 Red down OPEN` | 下降到能夹住提手两侧的高度，保持张开，不压篮体。 |
| `3 Red down GRIP` | 尽量保持机械臂和手腕姿态不变，手动合拢夹爪至贴合提手。抓力及防滑效果尚需后续单独验证。 |
| `4 Red lift GRIP` | 保持夹持朝向和开度，将物块托起，篮体底部高于周围物块及障碍。 |
| `5 T0 above GRIP` | 带着物块手动移到 T0 上方，保持足够离地高度。 |
| `6 T0 down GRIP` | 将篮体平稳放到 T0 地面，夹爪仍贴合提手，不继续向下压。 |
| `7 T0 down OPEN` | 尽量保持机械臂和手腕姿态不变，只张开夹爪，使其脱离提手。 |
| `8 T0 clear OPEN` | 夹爪张开，抬到提手上方，退出物块范围。 |

每次释放全部关节后，夹爪也失去保持力，所以需要手托物块，不能让它悬挂在无扭矩夹爪上。相邻物块可能妨碍抓取，现场逐点确认间隙。点位存储使用六个关节的编码器值，保留腕部姿态和夹爪开度；不是只存 XYZ，也不是用照片推算坐标。

## 数据与后续验证

- 108 字节记录含格式版本、顺序有效掩码、8×6 个 int16 编码器值、CRC32。写入失败不显示保存成功，保持锁定并允许重试。
- 命令 105 是只读导出接口。电脑脚本 `read_handle_teach.py` 校验帧、CRC、顺序和编码器范围，能导出 JSON 与原始记录。
- 电脑打开串口可能因驱动电平变化导致复位；读取前仍需托稳。脚本不会主动翻转复位引脚，不发送运动或扭矩命令。
- 八个点只是端点，不保证两点之间的直线下降、垂直抬升或无碰撞。自动回放前必须检查关节映射、夹爪行程、路径插值、避障间隙和执行速度，先空载逐段验证。
- 当前尚未修改自动抓取为该示教路径，也未声称能够直接抓取成功。
