# ID6 单独使能对照 r3

用户已确认夹爪空载、机械臂支撑、无异常，并明确授权上电检查且持续观察。

程序上电不自动试验，NVS八点只读。主机需发送精确一行`RUN_ID6_ONCE`；每次启动最多接受一次。不接受任意舵机透传命令。

顺序：五帧稳定基线→仅ID6写当前目标→等700ms并核对位置→仅ID6寄存器40写1→等800ms并核对位置→仅ID6写基线减8目标→观察4秒→仅ID6寄存器40写0。加速度5、速度30。

寄存器读回仍不可用；写入日志证明提交UART，不证明舵机接收。当前目标预写不能作为绝对无突动保证。现场必须空载、手指离开夹口并监视。

- 唯一UART写入口限制为FF/CMD65，或按阶段允许的ID6当前目标、ID6开力矩、小步目标、ID6关力矩。不向ID1～5发目标或力矩命令。
- 每个阶段命令最多一次，不重试；上力矩命令尝试后，失败路径也会尝试发送ID6释放。
- 反馈超过500ms未更新、保持阶段偏移超过4刻度、其他关节步进阶段偏移超过8刻度、ID6超出小步包络，立即转终态并尝试释放。
- 使能后6秒软件截止。KEY2可请求释放；主机`STOP_ID6`可请求释放。软件与通信可能失效，任何异常应现场托稳并切断外接舵机电源。
- 完成状态和结果每500ms重复输出，直至重启；不写NVS，不覆盖示教数据。

构建：`build_id6_torque_probe_r3.ps1`。采集默认只读：`capture_id6_torque_probe.py --reset`；动作由`capture_id6_torque_probe.py --run-once`触发，只有版本、自检、八点及稳定反馈都满足才发送一次开始命令。二者不能同时使用。

一次小步通过不代表完整开合、持重夹持或八点搬运已验证。
