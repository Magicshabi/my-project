# 八点搬运适配（2026-10-08）

入口：`examples/07_eight_point_pick_place.py`，执行层：`nexarm/eight_point.py`。
复用当前Python库和CMD8，不要求更换ESP32或AT32固件。

## 复用了什么

- `运动控制/编程定点夹取搬运`的完整位姿步骤表和分段搬运顺序。
- `运动控制/速度规划`的分阶段时长思路；未照搬示例中的工作点和加速度数值。
- 本目录解码库的CMD8载荷、串口、限位、机构参数、零偏读取接口。逆解与段内插补由AT32处理。
- 八点原始顺序及六轴计数全部保留在新标定文件的`legacy_encoders`，不覆盖原始bin/json。

旧记录只有编码器值，缺少同一标定下的XYZ/pitch/roll/claw。当前没有验证过的原计数→坐标转换，不能自动宣称迁移成功。新JSON的`pose=null`是明确待标定，不能执行；不填虚构坐标。

## 运动衔接方式

| 点 | 含义 | 动作约束 |
|---|---|---|
| 1 | 红提手上方，张爪 | 起始姿态须接近此点，不自动从任意位置回零 |
| 2 | 下探到提手，张爪 | 保持XY及朝向，以10mm/s规划时间 |
| 3 | 原位闭爪 | 保持臂姿；按夹爪角差规划时间，再停留400ms |
| 4 | 提起 | 沿Z抬升，保持夹持 |
| 5 | T0上方 | 完整位姿一次下发，多轴由AT32协调 |
| 6 | T0下放 | 保持XY及朝向，以10mm/s规划时间 |
| 7 | 原位松爪 | 保持臂姿，再停留400ms |
| 8 | 抬离T0 | 沿Z抬升，保持张爪 |

其他平移段按25mm/s、腕姿变化按12°/s、夹爪按30°/s计算所需时长，取最大值且每段至少800ms；超过15秒拒绝，不通过加速掩盖大跨度。单位是上层计划值，不宣称机械臂已经达到这些真实速度。

每段由AT32做插补，不再每8个编码器刻度等待停稳。夹持/松开必须独立，段与段之间仍检查完整位姿报告。这个方案是连贯的分段流程，**不保证段连接处速度连续，也不宣称实现了轨迹圆滑过渡**。CMD89插补模式在当前固件未证实支持，未使用。

上下方间距最低30mm、接触段不横移是几何检查，不代替现场碰撞检查或逆解分支验证。坐标系必须是同一基座坐标系，机械臂固定方式和提手位置改变后应重新校准。

## 预览、逐点验证、连贯运行

```powershell
python -B 舵机基础运行逻辑\examples\07_eight_point_pick_place.py plan
python -B 舵机基础运行逻辑\examples\07_eight_point_pick_place.py run --go
# 仅在同一份标定已逐段现场验证后使用：
python -B 舵机基础运行逻辑\examples\07_eight_point_pick_place.py run --go --continuous --path-reviewed
```

`plan`完全离线，不指定`--current X Y Z P R C`时明确假设从第1点开始。`run`会重新读取实际设备配置与控制器当前位姿，起点距离第1点任一XYZ轴超过20mm或任一角度超过5°就拒绝。各段前重新检查报告仍在前一点附近。

默认逐点模式每到一点要求操作者输入`yes`确认物理状态再推进。连贯模式取消人工逐点停顿，但仍保留段间控制器检查和夹爪停留，不能仅凭回包标记真实定位精度通过。

不自动开启/关闭力矩，不自动回零；需使用当前固件已验证的启动力矩流程，不能盲目按KEY1套用不同固件的说明。

## 本轮修复与限制

- `ArmController.move_to(wait=True)`失败会抛出超时，`move_path`不会静默推进。
- 到位等待检查XYZ及pitch/roll/claw，至少3次报告、跨度至少0.2秒，缺报告清空计数；尊重预定运动时间。
- 串口短写报错、不重发；接收线程异常后标记不可用；系统请求过滤非系统ID回包。
- 控制器CMD11/CMD65/CMD66的物理反馈真实性尚需独立验证。两个回包相同本身不能证明数据源独立，也不能证明它们必然是目标缓存。本实现保守标注为“控制器报告”，不把它包装成物理闭环。
- 既有20:18记录展示的是控制器位姿及报告者的实机结论，未包含本轮独立物理测量；规格中的“当前诊断固件需KEY1”与19:11已恢复程序的记录不同，不能直接套用到当前硬件。
- Ctrl+C或运行日志目录的`STOP`文件会停止后续下发。**没有已验证的坐标运动急停接口，当前AT32段可能继续执行**；出现异常需由现场支撑并断舵机电源。脚本不会乱发反向运动、力矩关闭或用不可信当前位置强制保持。

本轮仅开发和离线测试，没有打开COM口、刷机或执行机械臂运动。
